## 1. Fi'il: Klasifikasi dan Jenis

### Berdasarkan Jumlah Huruf Asal
| Jenis | Huruf | Contoh |
|-------|-------|--------|
| Tsulatsi (3 huruf) | ف ع ل | كَتَبَ |
| Ruba'i (4 huruf) | ف ع ل ل | دَحْرَجَ |

### Berdasarkan Tambahan (Ziyadah)
- **Mujarrad**: tanpa tambahan → كَتَبَ
- **Mazid**: dengan tambahan huruf → أَكْرَمَ، كَاتَبَ، انْكَسَرَ

### Berdasarkan Huruf (Shahih vs Mu'tal)
- **Shahih**: semua huruf shahih (bukan huruf 'illah)
  - Salim: كَتَبَ
  - Mudha'af: مَدَّ (faa' = 'ain atau 'ain = lam)
  - Mahmuuz: قَرَأَ، أَكَلَ (mengandung hamzah)
- **Mu'tal**: mengandung و atau ي sebagai huruf asal
  - Mitsali: وَعَدَ (faa' fi'il = و/ي)
  - Ajwaf: قَالَ، بَاعَ ('ain fi'il = و/ي)
  - Naqish: دَعَا، رَمَى (lam fi'il = و/ي)
  - Lafif maqrun: وَقَى (faa' + lam mu'tal)
  - Lafif mafruq: وَلِيَ (faa' + 'ain mu'tal... naqish juga)

### Berdasarkan Ketransitifan
- **Lazim** (intransitif): tidak perlu maf'ul → ذَهَبَ، جَلَسَ
- **Muta'addi** (transitif): memerlukan maf'ul → كَتَبَ، ضَرَبَ
- Muta'addi bisa ke satu, dua, atau tiga maf'ul (أَعْطَى، عَلَّمَ، ظَنَّ)

## 2. Fi'il Tsulatsi Mujarrad: 6 Bab

| Bab | Madhi | Mudhari' | Ciri | Contoh |
|-----|-------|----------|------|--------|
| 1 | فَعَلَ | يَفْعُلُ | 'ain madhi fathah, mudhari' dhammah | نَصَرَ يَنْصُرُ |
| 2 | فَعَلَ | يَفْعِلُ | 'ain madhi fathah, mudhari' kasrah | ضَرَبَ يَضْرِبُ |
| 3 | فَعَلَ | يَفْعَلُ | 'ain madhi fathah, mudhari' fathah | فَتَحَ يَفْتَحُ |
| 4 | فَعِلَ | يَفْعَلُ | 'ain madhi kasrah, mudhari' fathah | عَلِمَ يَعْلَمُ |
| 5 | فَعُلَ | يَفْعُلُ | 'ain madhi dhammah, mudhari' dhammah | كَرُمَ يَكْرُمُ |
| 6 | فَعِلَ | يَفْعِلُ | 'ain madhi kasrah, mudhari' kasrah | حَسِبَ يَحْسِبُ |

> ⚠️ Bab 5 (فَعُلَ) umumnya untuk sifat tetap dan lazim (tidak bisa jadi muta'addi). Bab 6 jarang.
> Tidak ada bab فَعُلَ يَفْعِلُ atau فَعُلَ يَفْعَلُ.

## 3. Fi'il Ruba'i Mujarrad

Satu bab saja: **فَعْلَلَ يُفَعْلِلُ**
Contoh: دَحْرَجَ يُدَحْرِجُ (menggelindingkan)، زَلْزَلَ يُزَلْزِلُ (mengguncangkan)

Masdarnya: فَعْلَلَةٌ → دَحْرَجَةٌ، زَلْزَلَةٌ

## 4. Fi'il Tsulatsi Mazid: Wazan & Makna

### Mazid Satu Huruf

#### أَفْعَلَ (Bab IV)
**Makna utama:**
- Ta'diyah (menjadikan transitif): جَلَسَ → أَجْلَسَهُ (mendudukkannya)
- Dakhul waktu: أَصْبَحَ (masuk waktu pagi)
- Dakhul tempat: أَنْجَدَ (masuk Najd)
- Wujudan shifat: أَثْمَرَ (berbuah)
- Shaluratur (menganggap): أَكْرَمَهُ (menganggapnya mulia)

#### فَعَّلَ (Bab II)
**Makna utama:**
- Ta'diyah + taksir (banyak/berulang): كَسَّرَ (menghancurkan berkali-kali)
- Nisbah: كَفَّرَ (mengkafirkan), فَسَّقَ (memfasikkan)
- Ta'lim (mengajari): عَلَّمَ (mengajar)
- Suluk (menganggap): كَذَّبَهُ (mendustakannya)

#### فَاعَلَ (Bab III)
**Makna utama:**
- Musyarakah (partisipasi dua pihak): ضَارَبَ (saling memukul), قَاتَلَ (saling bertempur)
- Muwalaah (berurutan): سَافَرَ (bepergian berulang), تَابَعَ

### Mazid Dua Huruf

#### انْفَعَلَ (Bab VII)
**Makna utama:**
- Muthawaah أَفْعَلَ (hasil/dampak dari): أَنْكَسَرَ ← كَسَرَهُ (ia pun patah setelah dipatahkan)
- Lazim (tidak transitif)

#### افْتَعَلَ (Bab VIII)
**Makna utama:**
- Muthawaah فَعَّلَ: اجْتَمَعَ ← جَمَّعَهُمْ
- Musyarakah: اقْتَتَلَ (saling membunuh)
- Ta'diyah: اكْتَسَبَ (mengusahakan)
- Ittikhadz (menjadikan): اتَّخَذَ

**Perubahan ta' افتعل:**
| Faa' | Ta' → | Contoh |
|------|-------|--------|
| د، ذ، ز | → د | ادَّكَرَ، ازْدَادَ |
| ص، ض، ط، ظ | → ط | اصْطَبَرَ، اضْطَرَبَ |
| و | ت → ت (وَصَلَ → اتَّصَلَ) | اتَّصَلَ |

#### افْعَلَّ (Bab IX)
**Makna utama:**
- Khusus warna dan cacat fisik: اِحْمَرَّ (menjadi merah)، اِعْوَرَّ (menjadi buta sebelah)
- Hanya lazim

#### تَفَعَّلَ (Bab V)
**Makna utama:**
- Muthawaah فَعَّلَ: تَعَلَّمَ ← عَلَّمَهُ (ia pun belajar)
- Takalluf (berpura-pura/berusaha): تَصَبَّرَ (bersabar dengan usaha)
- Muthawaah: تَكَسَّرَ (menjadi hancur-hancuran)

#### تَفَاعَلَ (Bab VI)
**Makna utama:**
- Muthawaah فَاعَلَ: تَضَارَبَا ← ضَارَبَا
- Musyarakah: تَشَارَكَ (saling berbagi)
- Tahawwul (berpura-pura jadi): تَمَارَضَ (pura-pura sakit)

### Mazid Tiga Huruf

#### اسْتَفْعَلَ (Bab X)
**Makna utama:**
- Thalab (meminta): اسْتَغْفَرَ (meminta ampunan)، اسْتَعَانَ (meminta pertolongan)
- Ra'y (menganggap): اسْتَحْسَنَ (menganggap baik)
- Tahawwul (menjadi): اسْتَحْجَرَ (menjadi batu)
- Muthawaah: اسْتَقَرَّ

#### افْعَوْعَلَ
**Makna:** mubalaghah (penguatan sifat lazim)
اِغْدَوْدَنَ (menjadi sangat lebat — rambut/tumbuhan)

#### افْعَوَّلَ
**Makna:** mubalaghah
اِجْلَوَّذَ (berjalan sangat cepat)

#### افْعَالَّ
**Makna:** penguatan warna/cacat
اِحْمَارَّ (sangat merah)

## 6. Fi'il Mu'tal

### 6a. Fi'il Mitsali (Faa' = و atau ي)

**Mitsali Wawi (bab فَعَلَ يَفْعِلُ):**
- Dalam mudhari': faa' (و) dibuang → وَعَدَ يَعِدُ، وَصَلَ يَصِلُ
- Dalam amar: وَعَدَ → عِدْ (tanpa faa')

**Mitsali Yaa'i:** jarang, و tetap → يَئِسَ يَيْأَسُ (versi tertentu)

**Mitsali bab فَعِلَ يَفْعَلُ:** و tidak dibuang → وَجِلَ يَوْجَلُ

### 6b. Fi'il Ajwaf ('Ain = و atau ي)

**Ajwaf Wawi:** قَالَ أصله قَوَلَ
| Bentuk | Perubahan | Hasil |
|--------|-----------|-------|
| Madhi mufrad mudzakkar | قَوَلَ → قَالَ | Alif |
| Madhi dhamir جمع مذكر | قَالُوا | |
| Madhi dhamir مثنى | قَالَا | |
| Mudhari' | يَقُوْلُ | Waw |
| Majzum mudhari' | لَمْ يَقُلْ | Dibuang |
| Amar | قُلْ | |

**Ajwaf Yaa'i:** بَاعَ أصله بَيَعَ
| Bentuk | Perubahan | Hasil |
|--------|-----------|-------|
| Madhi | بَاعَ | Alif |
| Mudhari' | يَبِيْعُ | Ya' |
| Majzum | لَمْ يَبِعْ | Dibuang |
| Amar | بِعْ | |

### 6c. Fi'il Naqish (Lam = و atau ي)

**Naqish Wawi:** دَعَا أصله دَعَوَ
| Bentuk | Perubahan | Hasil |
|--------|-----------|-------|
| Madhi mufrad | دَعَا | Alif maqshur |
| Madhi jamak mudzakkar | دَعَوْا | |
| Mudhari' | يَدْعُو | Waw |
| Majzum | لَمْ يَدْعُ | Dibuang |
| Amar | اُدْعُ | |

**Naqish Yaa'i:** رَمَى أصله رَمَيَ
| Bentuk | Perubahan | Hasil |
|--------|-----------|-------|
| Madhi mufrad | رَمَى | Alif |
| Madhi jamak mudzakkar | رَمَوْا | |
| Mudhari' | يَرْمِي | Ya' |
| Majzum | لَمْ يَرْمِ | Dibuang |
| Amar | اِرْمِ | |

### 6d. Lafif Maqrun (Faa' & Lam Mu'tal)
وَقَى يَقِي — seperti kombinasi mitsali + naqish

### 6e. Lafif Mafruq (Faa' & 'Ain Mu'tal — naqish yaa'i)
وَلِيَ يَلِي، وَشَى يَشِي

## 7. Fi'il Mudha'af (Huruf Ke-2 = Ke-3)

### Tsulatsi Mudha'af
مَدَّ أصله مَدَدَ، شَدَّ أصله شَدَدَ

**Kaidah idgham:** huruf yang sama bergabung dengan tasydid, kecuali jika disambung huruf mati:
- مَدَدْتُ (tidak diidgham karena ada سكون)
- مَدَّ (diidgham)

| Bentuk | Contoh |
|--------|--------|
| Madhi mufrad | مَدَّ |
| Madhi dhamir متكلم | مَدَدْتُ |
| Mudhari' | يَمُدُّ |
| Majzum | لَمْ يَمُدَّ / لَمْ يَمُدُدْ (keduanya boleh) |
| Amar | مُدَّ / اُمْدُدْ |

## 9. Masdar dan Jenisnya

### Masdar Qiyasi (Beraturan)
| Wazan Fi'il | Wazan Masdar Umum | Contoh |
|-------------|-------------------|--------|
| فَعَلَ يَفْعُلُ | فَعْلٌ | نَصَرَ → نَصْرٌ |
| فَعَلَ يَفْعِلُ | فَعْلٌ / فِعَالٌ | ضَرَبَ → ضَرْبٌ |
| فَعِلَ يَفْعَلُ | فَعَلٌ | فَرِحَ → فَرَحٌ |
| فَعُلَ يَفْعُلُ | فَعَالَةٌ | كَرُمَ → كَرَامَةٌ |
| أَفْعَلَ | إِفْعَالٌ | أَكْرَمَ → إِكْرَامٌ |
| فَعَّلَ | تَفْعِيْلٌ | عَلَّمَ → تَعْلِيْمٌ |
| فَاعَلَ | فِعَالٌ / مُفَاعَلَةٌ | قَاتَلَ → قِتَالٌ |
| انْفَعَلَ | انْفِعَالٌ | انْكَسَرَ → انْكِسَارٌ |
| افْتَعَلَ | افْتِعَالٌ | اجْتَمَعَ → اجْتِمَاعٌ |
| تَفَعَّلَ | تَفَعُّلٌ | تَعَلَّمَ → تَعَلُّمٌ |
| تَفَاعَلَ | تَفَاعُلٌ | تَشَارَكَ → تَشَارُكٌ |
| اسْتَفْعَلَ | اسْتِفْعَالٌ | اسْتَغْفَرَ → اسْتِغْفَارٌ |
| فَعْلَلَ | فَعْلَلَةٌ | دَحْرَجَ → دَحْرَجَةٌ |

### Masdar Sima'i (Tidak Beraturan)
Harus dihafal dari kamus karena tidak mengikuti pola tetap:
ذَهَبَ → ذَهَابٌ، ذَهْبٌ
رَجَعَ → رُجُوعٌ
أَكَلَ → أَكْلٌ
قَعَدَ → قُعُوْدٌ

### Masdar Mim (Masdar dengan Awalan Mim)
| Bab | Wazan | Contoh |
|-----|-------|--------|
| Tsulatsi bab 1-3 | مَفْعَلٌ / مَفْعِلٌ | مَكْتَبٌ، مَنْزِلٌ |
| Bab lainnya | Sama dengan isim makan | مُجْتَمَعٌ |

### Masdar Shnaaiy (Dua Masdar)
Beberapa fi'il punya dua masdar dengan makna berbeda:
- غَفَرَ: غَفْرٌ (perbuatan memaafkan) / غُفْرَانٌ (ampunan/hasil)
- كَفَرَ: كُفْرٌ (kekufuran sbg sifat) / كُفُوْرٌ (perbuatan kafir)

## 10. Isim Fa'il dan Isim Maf'ul

### Isim Fa'il (Pelaku)
| Bab Fi'il | Wazan Isim Fa'il |
|-----------|-----------------|
| Tsulatsi (semua bab) | فَاعِلٌ |
| أَفْعَلَ | مُفْعِلٌ |
| فَعَّلَ | مُفَعِّلٌ |
| فَاعَلَ | مُفَاعِلٌ |
| انْفَعَلَ | مُنْفَعِلٌ |
| افْتَعَلَ | مُفْتَعِلٌ |
| تَفَعَّلَ | مُتَفَعِّلٌ |
| تَفَاعَلَ | مُتَفَاعِلٌ |
| اسْتَفْعَلَ | مُسْتَفْعِلٌ |

> Pola umum mazid: **مُ + awal fi'il mudhari' + kasrah huruf sebelum akhir**

### Isim Maf'ul (Objek yang Dikenai)
| Bab Fi'il | Wazan Isim Maf'ul |
|-----------|--------------------|
| Tsulatsi | مَفْعُوْلٌ |
| Semua mazid | مُ + mudhari' + fathah akhir |

Contoh:
- أَكْرَمَ → مُكْرَمٌ (yang dimuliakan)
- عَلَّمَ → مُعَلَّمٌ (yang diajar)
- اسْتَخْدَمَ → مُسْتَخْدَمٌ (yang digunakan)

## 11. Shighah Mubalaghah (Hiperbola Pelaku)

Untuk menyatakan pelaku yang sangat sering/banyak melakukan sesuatu:

| Wazan | Makna Penekanan | Contoh |
|-------|-----------------|--------|
| فَعَّالٌ | Sangat banyak | عَلَّامٌ، كَذَّابٌ، صَوَّامٌ |
| مِفْعَالٌ | Sangat sering | مِطْعَانٌ، مِقْدَامٌ |
| فَعُوْلٌ | Sangat | شَكُوْرٌ، صَبُوْرٌ، غَفُوْرٌ |
| فَعِيْلٌ | Sifat mendalam | عَلِيْمٌ، قَدِيْرٌ، رَحِيْمٌ |
| فَعِلٌ | Sifat aktif | فَطِنٌ، يَقِظٌ، حَذِرٌ |

## 12. Isim Tafdhil (Komparatif & Superlatif)

### Pembentukan
Wazan: **أَفْعَلُ** (mudzakkar) / **فُعْلَى** (mu'annats)

أَكْبَرُ — أَصْغَرُ — أَكْرَمُ — أَجْمَلُ — أَحْسَنُ — أَفْضَلُ

### Penggunaan
**Komparatif** (lebih... dari): dengan مِنْ
هَذَا أَكْبَرُ مِنْ ذَاكَ

**Superlatif** (paling...) — tiga cara:
1. Ma'rifah: الْأَكْبَرُ (yang terbesar)
2. Idhafah: أَكْبَرُ الطُّلَّابِ (paling besar di antara siswa)
3. Nakirah: أَكْبَرُ طَالِبٍ (siswa yang paling besar)

### Syarat Pembentukan Langsung
Fi'il harus: tsulatsi, tidak mengandung warna/cacat (ada cara lain), positif, bisa ta'ajjub.
Jika tidak memenuhi syarat → gunakan perantara:
أَكْثَرُ اشْتِغَالًا (lebih sibuk) — karena اشتغل sextuple

## 13. Isim Zaman, Makan, dan Alat

### Isim Zaman & Makan (Waktu & Tempat)
| Bab | Wazan |
|-----|-------|
| Tsulatsi bab 1, 2, 3 (mudhari' berharakat fathah/'ain) | مَفْعَلٌ |
| Tsulatsi bab 4, 5, 6 (mudhari' 'ain kasrah) | مَفْعِلٌ |
| Semua mazid | Sama dengan masdar mim |

Contoh:
- كَتَبَ يَكْتُبُ → مَكْتَبٌ (tempat/waktu menulis)
- جَلَسَ يَجْلِسُ → مَجْلِسٌ (tempat duduk)
- اجْتَمَعَ → مُجْتَمَعٌ (masyarakat/tempat berkumpul)

### Isim Alat (Instrumen)
| Wazan | Contoh |
|-------|--------|
| مِفْعَلٌ | مِبْرَدٌ (kikir)، مِقَصٌّ (gunting) |
| مِفْعَلَةٌ | مِكْنَسَةٌ (sapu)، مِصْفَاةٌ (saringan) |
| مِفْعَالٌ | مِفْتَاحٌ (kunci)، مِيْزَانٌ (timbangan) |
| فَعَّالَةٌ (modern) | غَسَّالَةٌ (mesin cuci)، ثَلَّاجَةٌ (kulkas) |

## 14. Fi'il Amar dan Nahiy

### Fi'il Amar (Perintah)
Dibentuk dari fi'il mudhari' majzum:
1. Buang huruf mudharaah
2. Jika huruf pertama berharakat → langsung jadi amar
3. Jika sukun → tambahkan alif washal berharakat (kasrah pada umumnya, dhammah jika 'ain dhammah)

| Mudhari' | Amar |
|----------|------|
| يَكْتُبُ | اُكْتُبْ |
| يَضْرِبُ | اِضْرِبْ |
| يَنْصُرُ | اُنْصُرْ |
| يُكْرِمُ | أَكْرِمْ |
| يَقُوْمُ | قُمْ |
| يَرْمِي | اِرْمِ |
| يَدْعُو | اُدْعُ |

### Nahiy (Larangan)
لَا + fi'il mudhari' majzum:
لَا تَكْذِبْ، لَا تَكْسِلُوا، لَا تَيْأَسِي

## 15. Jamak: Semua Jenis

### Jamak Mutsanna (Dua)
Tambahkan: ـَانِ (marfu') / ـَيْنِ (manshub/majrur)
كِتَابٌ → كِتَابَانِ / كِتَابَيْنِ

### Jamak Mudzakkar Salim
Tambahkan: ـُوْنَ (marfu') / ـِيْنَ (manshub/majrur)
Hanya untuk manusia laki-laki: مُسْلِمُوْنَ، مُعَلِّمُوْنَ، مُجْتَهِدُوْنَ

### Jamak Mu'annats Salim
Tambahkan: ـَاتٌ / ـَاتٍ
Untuk mu'annats dan benda: مُسْلِمَاتٌ، سَيَّارَاتٌ، اتِّجَاهَاتٌ

### Jamak Taksir (Tidak Beraturan)
Harus dihafal per kata. Wazan-wazan umum:

| Wazan Mufrad | Wazan Jamak | Contoh |
|--------------|-------------|--------|
| فَعْلٌ | فُعُوْلٌ | قَلْبٌ → قُلُوْبٌ |
| فَعْلٌ | أَفْعَالٌ | فِعْلٌ → أَفْعَالٌ |
| فَاعِلٌ | فُعَّالٌ | كَاتِبٌ → كُتَّابٌ |
| فَاعِلٌ | فُعَلَاءُ | عَالِمٌ → عُلَمَاءُ |
| فَعِيْلٌ | أَفْعِلَاءُ | نَبِيٌّ → أَنْبِيَاءُ |
| فَعِيْلٌ | فُعَلَاءُ | كَرِيْمٌ → كُرَمَاءُ |
| فَعْلَانُ | فِعَالٌ | غَضْبَانُ → غِضَابٌ |
| فُعْلَةٌ | فُعَلٌ | غُرْفَةٌ → غُرَفٌ |
| فَعِيْلَةٌ | فَعَائِلُ | قَبِيْلَةٌ → قَبَائِلُ |
| مَفْعَلَةٌ | مَفَاعِلُ | مَدْرَسَةٌ → مَدَارِسُ |
| مَفْعُوْلٌ | مَفَاعِيْلُ | مَفْتُوْحٌ → مَفَاتِيْحُ |
| فَعَّالَةٌ | فَعَّالَاتٌ/فَعَاعِلُ | غَسَّالَةٌ → غَسَّالَاتٌ |

> ⚠️ مَفَاعِلُ dan مَفَاعِيْلُ adalah ghoiru munsharif (tidak menerima tanwin/kasrah)

### Jamak Jamak (Jamak dari Jamak)
Kadang digunakan untuk menekankan jumlah yang sangat banyak:
أَقْلَامٌ → أَقَالِيْمُ (jarang, hanya untuk kata tertentu)

## 16. Isim Manqush, Maqshur, Mamdud

### Isim Manqush
Isim yang diakhiri ya' bertasydid (ي) sebelumnya kasrah:
قَاضٍ، دَاعٍ، مُحَامٍ

**I'rab khusus:**
- Marfu' nakirah: قَاضٍ (tanwin kasrah, ya' dibuang)
- Manshub nakirah: قَاضِيًا (ya' kembali)
- Majrur nakirah: قَاضٍ
- Ma'rifah: الْقَاضِي (ya' tetap semua keadaan kecuali... tetap saja)

### Isim Maqshur
Isim yang diakhiri alif (ا atau ى):
الْفَتَى، الْمُسْتَشْفَى، الدُّنْيَا

**I'rab khusus:** i'rab dikira-kirakan (muqaddar) di atas alif — tidak terlihat:
- Marfu': الْفَتَى (taqdirinya dhammah)
- Manshub: الْفَتَى (taqdirinya fathah)
- Majrur: الْفَتَى (taqdirinya kasrah)

### Isim Mamdud
Isim yang diakhiri alif + hamzah (اء):
سَمَاءٌ، صَحْرَاءٌ، أَصْدِقَاءُ

**Jamak mamdud:**
- اء → اء (jika hamzah asli): قُرَّاءُ → قُرَّاؤُوْنَ (tidak ada)
- اء → اء: صَحْرَاءُ → صَحَارٍ / صَحَارَى

## 17. Nisbah (Kata Sifat Relasional)

Tambahkan ـِيٌّ / ـِيَّةٌ di akhir isim:
مِصْرُ → مِصْرِيٌّ (Mesir → orang Mesir)
إِسْلَامٌ → إِسْلَامِيٌّ (Islam → Islami)

**Perubahan saat nisbah:**
- Hapus ta' marbuthah: مَدْرَسَةٌ → مَدْرَسِيٌّ
- Hapus alif & nun akhir: رَمَضَانُ → رَمَضَانِيٌّ
- Alif maqshur 3 huruf → wawu: الْفَتَى → فَتَوِيٌّ
- Alif mamdud 4 huruf+ → boleh tetap atau ganti wawu: صَحْرَاءُ → صَحْرَاوِيٌّ
