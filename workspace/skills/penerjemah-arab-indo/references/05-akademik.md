## 1. Register & Karakteristik Bahasa Arab Akademik

Karya ilmiah Arab menggunakan **Modern Standard Arabic (MSA / الفصحى المعاصرة)** dengan ciri-ciri:

### Ciri Khas Arab Akademik
| Ciri | Penjelasan | Contoh |
|------|------------|--------|
| **Objektif & impersonal** | Hindari kata "saya" — lebih sering pasif atau persona jamak | يَتَنَاوَلُ هَذَا الْبَحْثُ (bukan أَتَنَاوَلُ) |
| **Tepat & tidak ambigu** | Pilih kata yang bermakna spesifik | اسْتَخْدَمَ (menggunakan secara teknis) vs أَخَذَ (mengambil, lebih umum) |
| **Formal & baku** | Gunakan MSA, hindari dialek | — |
| **Terstruktur** | Kalimat berlogika, berurutan, berkonjungsi jelas | لِذَلِكَ، وَمِنْ ثَمَّ، وَبِنَاءً عَلَيْهِ |
| **Menghindari tautologi** | Tidak mengulang makna yang sama tanpa tujuan | — |
| **Berharakat parsial** | Harakat pada kata-kata kritis saja (bukan penuh) | kata ambigu, istilah baru |

### Persona dalam Karya Ilmiah Arab
| Situasi | Pilihan Arab |
|---------|-------------|
| Menjelaskan isi penelitian | يَتَنَاوَلُ هَذَا الْبَحْثُ... / تَهْدُفُ هَذِهِ الدِّرَاسَةُ إِلَى... |
| Menyatakan temuan | أَظْهَرَتِ النَّتَائِجُ... / تَبَيَّنَ أَنَّ... |
| Memberi rekomendasi | يُوْصِي الْبَاحِثُ بِـ... / تُوْصِي الدِّرَاسَةُ بِـ... |
| Mengutip pendapat | يَرَى الْبَاحِثُ... / يَذْهَبُ فُلَانٌ إِلَى أَنَّ... |
| Merumuskan masalah | تَتَمَحْوَرُ إِشْكَالِيَّةُ الْبَحْثِ حَوْلَ... |

## 2. Struktur Karya Ilmiah Arab

### 2a. Makalah/Paper (مَقَالَة بَحْثِيَّة)

```
1. الْعُنْوَانُ          — Judul
2. الْمُلَخَّصُ          — Abstrak (Arab + Inggris)
3. الْكَلِمَاتُ الْمِفْتَاحِيَّةُ — Kata Kunci
4. الْمُقَدِّمَةُ         — Pendahuluan
   - Latar belakang (الْخَلْفِيَّةُ / الإِطَارُ الْعَامُّ)
   - Rumusan masalah (إِشْكَالِيَّةُ الْبَحْثِ)
   - Tujuan penelitian (أَهْدَافُ الْبَحْثِ)
   - Pertanyaan penelitian (أَسْئِلَةُ الْبَحْثِ)
   - Hipotesis (الْفَرَضِيَّاتُ) — jika ada
   - Manfaat (أَهَمِّيَّةُ الْبَحْثِ)
   - Metodologi (مَنْهَجُ الْبَحْثِ)
5. الإِطَارُ النَّظَرِيُّ   — Kajian Teori / Tinjauan Pustaka
6. الإِجْرَاءَاتُ         — Metodologi Rinci
7. النَّتَائِجُ وَالتَّحْلِيلُ — Hasil dan Pembahasan
8. الْخَاتِمَةُ           — Kesimpulan
   - الاسْتِنْتَاجَاتُ (simpulan)
   - التَّوْصِيَاتُ (rekomendasi)
9. قَائِمَةُ الْمَصَادِرِ وَالْمَرَاجِعِ — Daftar Pustaka
```

### 2b. Skripsi/Tesis/Disertasi (رِسَالَة)

```
غِلَافُ الرِّسَالَةِ     — Halaman Sampul
إِقْرَارٌ               — Pernyataan Keaslian
الشُّكْرُ وَالتَّقْدِيرُ  — Ucapan Terima Kasih
الإِهْدَاءُ             — Persembahan (opsional)
الْمُلَخَّصُ             — Abstrak
فَهْرِسُ الْمُحْتَوَيَاتِ — Daftar Isi
قَائِمَةُ الْجَدَاوِلِ    — Daftar Tabel
قَائِمَةُ الأَشْكَالِ    — Daftar Gambar
الْفَصْلُ الأَوَّلُ: الإِطَارُ الْعَامُّ لِلْبَحْثِ
الْفَصْلُ الثَّانِي: الإِطَارُ النَّظَرِيُّ
الْفَصْلُ الثَّالِثُ: مَنْهَجُ الْبَحْثِ
الْفَصْلُ الرَّابِعُ: عَرْضُ الْبَيَانَاتِ وَتَحْلِيلُهَا
الْفَصْلُ الْخَامِسُ: الاسْتِنْتَاجَاتُ وَالتَّوْصِيَاتُ
الْمَرَاجِعُ
الْمَلَاحِقُ             — Lampiran
```

## 4. Frasa Pembuka dan Transisi Akademik

### Pembuka Pendahuluan
```
يَتَنَاوَلُ هَذَا الْبَحْثُ...          (Penelitian ini membahas...)
تَهْدُفُ هَذِهِ الدِّرَاسَةُ إِلَى...   (Studi ini bertujuan untuk...)
تَسْعَى هَذِهِ الْوَرَقَةُ إِلَى...    (Makalah ini berusaha untuk...)
يَنْطَلِقُ هَذَا الْبَحْثُ مِنْ...     (Penelitian ini berangkat dari...)
تَتَمَحْوَرُ إِشْكَالِيَّةُ هَذِهِ الدِّرَاسَةِ حَوْلَ... (Masalah penelitian berpusat pada...)
يَطْرَحُ هَذَا الْبَحْثُ تَسَاؤُلًا جَوْهَرِيًّا مَفَادُهُ: ... (Penelitian ini mengajukan pertanyaan fundamental, yaitu:...)
```

### Menyatakan Tujuan
```
يَرْمِي هَذَا الْبَحْثُ إِلَى...       (Penelitian ini bertujuan untuk...)
الْهَدَفُ الرَّئِيسِيُّ مِنْ هَذِهِ الدِّرَاسَةِ هُوَ... (Tujuan utama penelitian ini adalah...)
تَسْعَى الدِّرَاسَةُ إِلَى تَحْقِيقِ الأَهْدَافِ التَّالِيَةِ: (Penelitian berusaha mencapai tujuan berikut:)
```

### Transisi Penambahan
```
فَضْلًا عَنْ ذَلِكَ...               (Selain itu...)
يُضَافُ إِلَى مَا سَبَقَ...          (Ditambah dengan hal sebelumnya...)
وَعَلَاوَةً عَلَى ذَلِكَ...           (Lebih jauh lagi...)
كَذَلِكَ...                          (Demikian pula...)
وَبِالْمِثْلِ...                     (Dan serupa dengan itu...)
إِضَافَةً إِلَى مَا تَقَدَّمَ...       (Sebagai tambahan dari yang telah dipaparkan...)
```

### Transisi Kontras/Pertentangan
```
غَيْرَ أَنَّ...                      (Namun...)
بَيْدَ أَنَّ...                      (Akan tetapi...)
إِلَّا أَنَّ...                      (Meski demikian...)
فِي الْمُقَابِلِ...                   (Sebaliknya...)
عَلَى النَّقِيضِ مِنْ ذَلِكَ...       (Berlawanan dengan hal itu...)
بَيْنَمَا...                         (Sementara...)
فِي حِيْنِ أَنَّ...                   (Padahal...)
```

### Transisi Sebab-Akibat
```
لِذَلِكَ...                          (Oleh karena itu...)
وَمِنْ ثَمَّ...                      (Dan dengan demikian...)
وَبِنَاءً عَلَيْهِ...                 (Berdasarkan hal itu...)
نَتِيجَةً لِذَلِكَ...                 (Sebagai akibatnya...)
وَيَتَرَتَّبُ عَلَى ذَلِكَ...         (Dan yang menjadi konsekuensinya adalah...)
مِمَّا أَفْضَى إِلَى...               (Yang mengakibatkan...)
```

### Transisi Urutan/Enumerasi
```
أَوَّلًا...، ثَانِيًا...، ثَالِثًا...  (Pertama...Kedua...Ketiga...)
فِي الْمَرْحَلَةِ الأُولَى...         (Pada tahap pertama...)
يَنْقَسِمُ هَذَا الْبَحْثُ إِلَى...   (Penelitian ini terbagi menjadi...)
وَتَشْمَلُ هَذِهِ الْجَوَانِبُ...     (Dan aspek-aspek ini mencakup...)
```

### Transisi Contoh
```
عَلَى سَبِيلِ الْمِثَالِ...           (Misalnya...)
وَمِنْ أَبْرَزِ الأَمْثِلَةِ عَلَى ذَلِكَ... (Di antara contoh paling menonjol dari hal itu adalah...)
وَيَتَجَلَّى ذَلِكَ فِي...            (Dan hal itu tampak jelas dalam...)
وَيَتَضِحُ هَذَا مِنْ خِلَالِ...      (Dan ini menjadi jelas melalui...)
```

### Transisi Kesimpulan
```
خُلَاصَةُ الْقَوْلِ...                (Kesimpulannya...)
وَبِنَاءً عَلَى مَا سَبَقَ...         (Berdasarkan uraian di atas...)
وَمِمَّا تَقَدَّمَ يَتَّضِحُ أَنَّ... (Dari apa yang telah dipaparkan, jelaslah bahwa...)
وَخُلَاصَةُ مَا تَوَصَّلَ إِلَيْهِ الْبَحْثُ: ... (Dan kesimpulan yang dicapai penelitian adalah:...)
وَتَكْشِفُ النَّتَائِجُ السَّابِقَةُ عَنْ... (Dan temuan di atas mengungkap...)
```

### Merujuk pada Literatur
```
يَرَى [اسم الباحث] أَنَّ...          (... berpendapat bahwa...)
يَذْهَبُ [اسم] إِلَى أَنَّ...        (... menyatakan bahwa...)
وَفْقًا لِـ [اسم]...                 (Menurut...)
كَمَا أَشَارَ [اسم] إِلَى أَنَّ...   (Sebagaimana yang ditunjukkan oleh...bahwa...)
وَفِي هَذَا الصَّدَدِ يَقُولُ [اسم]: (Dalam hal ini ... mengatakan:)
وَقَدْ أَكَّدَ [اسم] عَلَى أَنَّ... (Dan ... menegaskan bahwa...)
وَتَتَّفِقُ هَذِهِ الدِّرَاسَةُ مَعَ... (Penelitian ini sejalan dengan...)
وَتَخْتَلِفُ هَذِهِ الدِّرَاسَةُ عَنْ... (Penelitian ini berbeda dari...)
```

## 5. Uslub Kalimat Akademik

### Kalimat Definisi
```
يُعَرَّفُ [الْمُصْطَلَحُ] بِأَنَّهُ...   (... didefinisikan sebagai...)
يُقْصَدُ بِـ[المصطلح]...               (Yang dimaksud dengan...adalah...)
[المصطلح] هُوَ/هِيَ...                 (...adalah...)
وَيَتَمَيَّزُ [المفهوم] بِـ...           (Dan ... dicirikan dengan...)
```

### Kalimat Hipotesis
```
يَفْتَرِضُ الْبَاحِثُ أَنَّ...          (Peneliti mengasumsikan bahwa...)
تَنْطَلِقُ الدِّرَاسَةُ مِنْ فَرَضِيَّةِ أَنَّ... (Penelitian berangkat dari hipotesis bahwa...)
وَقَدْ أَمْكَنَ التَّحَقُّقُ مِنْ أَنَّ... (Dan telah dapat dipastikan bahwa...)
```

### Kalimat Pasif Akademik (Sangat Umum dalam Arab Akademik)
```
لُوحِظَ أَنَّ...                      (Ditemukan / Diobservasi bahwa...)
تَبَيَّنَ أَنَّ...                     (Terbukti bahwa...)
ثَبَتَ أَنَّ...                       (Terbukti secara pasti bahwa...)
أُكِّدَ أَنَّ...                      (Dikonfirmasi bahwa...)
وَقَدْ أَظْهَرَتِ الدِّرَاسَةُ أَنَّ... (Dan studi menunjukkan bahwa...)
```

### Kalimat Pembatasan Ruang Lingkup
```
تَقْتَصِرُ هَذِهِ الدِّرَاسَةُ عَلَى...  (Penelitian ini terbatas pada...)
لَا يَتَنَاوَلُ هَذَا الْبَحْثُ...       (Penelitian ini tidak membahas...)
يَنْحَصِرُ نِطَاقُ الدِّرَاسَةِ فِي...   (Cakupan penelitian terbatas pada...)
```

## 6. Cara Menulis Argumen & Analisis

### Struktur Paragraf Akademik Arab
Paragraf ilmiah Arab idealnya memiliki:
1. **الْجُمْلَةُ الرَّئِيسِيَّةُ** (kalimat topik) — pernyataan utama
2. **الشَّرْحُ وَالتَّوْضِيحُ** (elaborasi) — penjelasan + bukti
3. **الأَمْثِلَةُ** (contoh/data)
4. **الرَّبْطُ** (penghubung ke paragraf berikutnya atau simpulan mini)

### Pola Argumen
**Deduktif (umum → khusus):**
```
[Pernyataan umum]. وَيَتَجَلَّى ذَلِكَ فِي [perincian]. فَعَلَى سَبِيلِ الْمِثَالِ [contoh]. وَمِنْ ثَمَّ [simpulan].
```

**Induktif (khusus → umum):**
```
لُوحِظَ أَنَّ [data/fakta spesifik]. وَبِالنَّظَرِ إِلَى [fakta lain]. وَبِتَحْلِيلِ هَذِهِ الشَّوَاهِدِ يَتَّضِحُ أَنَّ [simpulan umum].
```

**Komparatif:**
```
يَتَّفِقُ [A] مَعَ [B] فِي [persamaan]. بَيْدَ أَنَّهُمَا يَخْتَلِفَانِ فِي [perbedaan]. وَيَرْجِعُ هَذَا الاخْتِلَافُ إِلَى [sebab].
```

## 7. Penulisan Definisi, Klasifikasi, Perbandingan

### Definisi
```
يُعَرَّفُ الذَّكَاءُ الاصْطِنَاعِيُّ بِأَنَّهُ قُدْرَةُ الأَنْظِمَةِ الْحَاسُوبِيَّةِ عَلَى مُحَاكَاةِ السُّلُوكِ الإِنْسَانِيِّ.
(AI didefinisikan sebagai kemampuan sistem komputer untuk meniru perilaku manusia.)
```

### Klasifikasi
```
تَنْقَسِمُ/تَتَوَزَّعُ أَنْوَاعُ [X] إِلَى ثَلَاثَةِ أَقْسَامٍ:
أَوَّلُهَا: [A]، وَهُوَ...
وَثَانِيهَا: [B]، وَيَتَّصِفُ بِـ...
وَثَالِثُهَا: [C]، وَيَتَمَيَّزُ بِـ...
```

### Perbandingan
```
وَإِذَا مَا قَارَنَّا [A] بِـ[B]، تَبَيَّنَ لَنَا أَنَّ كِلَيْهِمَا يَشْتَرِكَانِ فِي [persamaan]،
غَيْرَ أَنَّ [A] يَنْفَرِدُ بِـ[kekhususan A]، فِي حِيْنِ يَخْتَصُّ [B] بِـ[kekhususan B].
```

## 9. Penulisan Abstrak (مُلَخَّص)

### Struktur Abstrak Arab
Abstrak ilmiah Arab biasanya memuat (dalam 150-250 kata):

```
[1] هَدَفَتِ الدِّرَاسَةُ إِلَى... (Tujuan penelitian)
[2] اعْتَمَدَتِ الدِّرَاسَةُ عَلَى الْمَنْهَجِ... (Metode yang digunakan)
[3] تَكَوَّنَتِ الْعَيِّنَةُ مِنْ... (Sampel — jika ada)
[4] وَقَدْ تَوَصَّلَتِ الدِّرَاسَةُ إِلَى جُمْلَةٍ مِنَ النَّتَائِجِ أَبْرَزُهَا:... (Temuan utama)
[5] وَفِي ضَوْءِ هَذِهِ النَّتَائِجِ تُوْصِي الدِّرَاسَةُ بِـ... (Rekomendasi)
```

## 10. Kesalahan Umum dalam Arab Akademik

| Kesalahan | Penjelasan | Yang Benar |
|-----------|------------|------------|
| Menggunakan أَنَا berlebihan | Arab akademik cenderung impersonal | يَرَى الْبَاحِثُ / يَتَبَيَّنُ |
| Kalimat terlalu panjang tanpa titik | Mempersulit pemahaman | Pecah menjadi kalimat-kalimat terpisah |
| Campur aduk MSA dan dialek | Tidak profesional | Konsisten gunakan MSA |
| Terjemahan kaku kata per kata dari BI | Menghasilkan Arab yang tidak idiomatik | Terjemahkan gagasan, bukan kata |
| Salah gender istilah modern | Banyak istilah sains punya gender konvensional | Rujuk kamus Arab akademik |
| Menggunakan حَيْثُ secara berlebihan | Sering digunakan salah tempat | Gunakan إِذْ atau restrukturisasi |
| Salah penggunaan إِنَّ vs أَنَّ | إِنَّ untuk jumlah mustaqillah; أَنَّ setelah fi'l | — |
| لكن vs لكنّ | لكن = harf athaf (tanpa amal); لكنّ = nawasikh | Bedakan konteksnya |

## 11. Perbedaan Gaya: Akademik vs Non-Formal

Ini adalah panduan utama bagi agent untuk menawarkan pilihan kepada pengguna.

| Aspek | Akademik/Formal (رَسْمِيٌّ) | Non-Formal (غَيْرُ رَسْمِيٍّ) |
|-------|--------------------------|--------------------------|
| **Persona** | Impersonal (الباحث، الدراسة) | Orang pertama (أنا، نحن) |
| **Kosakata** | Tinggi, spesifik, baku | Umum, sehari-hari |
| **Kalimat** | Panjang, terstruktur, berkonjungsi | Pendek, langsung |
| **Pasif** | Sangat sering | Jarang |
| **Transisi** | Formal (من ثمّ، بناءً على، فضلًا عن) | Sederhana (و، ف، ثم) |
| **Emosi** | Dihindari, netral | Boleh ekspresif |
| **Contoh gaya** | يَتَبَيَّنُ مِنْ خِلَالِ الدِّرَاسَةِ أَنَّ الظَّاهِرَةَ تَرْتَبِطُ بِعَوَامِلَ مُتَعَدِّدَةٍ | الظَّاهِرَةُ مُرْتَبِطَةٌ بِعَوَامِلَ كَثِيرَةٍ |

### Tanda-tanda bahwa pengguna butuh gaya akademik:
- Menyebut: skripsi, tesis, disertasi, makalah, jurnal, paper, karya ilmiah
- Ada istilah seperti: metodologi, hipotesis, variabel, tinjauan pustaka
- Teks yang diserahkan terlihat formal dan terstruktur
- Pengguna menyebut kampus, dosen, sidang

### Tanda-tanda gaya non-formal:
- Menyebut: cerita, percakapan, pesan, posting, artikel blog
- Teks santai, banyak kata sehari-hari
- Tidak ada struktur ilmiah
