## 1. Kalimat Arab

### Jumlah Ismiyyah (Kalimat Nominal)
Terdiri dari **Mubtada + Khabar**

| Komponen | I'rab | Contoh |
|----------|-------|--------|
| Mubtada | Marfu' | اَلْعِلْمُ |
| Khabar | Marfu' | نُوْرٌ |

**Jenis Khabar:**
- **Khabar mufrad**: satu kata → اَلْبَيْتُ كَبِيْرٌ
- **Khabar jumlah ismiyyah**: kalimat nominal → اَلطَّالِبُ أَبُوْهُ مُجْتَهِدٌ
- **Khabar jumlah fi'liyyah**: kalimat verbal → اَلْوَلَدُ يَلْعَبُ
- **Khabar syibhul jumlah**: jar-majrur / zharaf → اَلْكِتَابُ عَلَى الْمَكْتَبِ

**Mubtada nakirah** diperbolehkan jika:
- Didahului nafyi: مَا أَحَدٌ فِي الدَّارِ
- Didahului istifham: هَلْ رَجُلٌ عِنْدَكَ؟
- Diikuti sifat: رَجُلٌ كَرِيْمٌ خَيْرٌ مِنْ بَخِيْلٍ

---

### Jumlah Fi'liyyah (Kalimat Verbal)
Urutan dasar: **Fi'il + Fa'il + Maf'ul bih**

**Kaidah muthâbaqah fi'il dan fa'il:**
| Fa'il | Fi'il |
|-------|-------|
| Mudzakkar mufrad | كَتَبَ / يَكْتُبُ |
| Mu'annats mufrad | كَتَبَتْ / تَكْتُبُ |
| Mudzakkar mutsanna | كَتَبَا / يَكْتُبَانِ |
| Mu'annats mutsanna | كَتَبَتَا / تَكْتُبَانِ |
| Mudzakkar jamak | كَتَبُوْا / يَكْتُبُوْنَ |
| Mu'annats jamak | كَتَبْنَ / يَكْتُبْنَ |

> ⚠️ Jika fa'il datang SEBELUM fi'il (inversi), fi'il wajib mufrad:
> الطُّلَّابُ كَتَبُوا ✓ (fa'il setelah fi'il → jamak)
> كَتَبَ الطُّلَّابُ ✓ (fa'il sebelum, fi'il tetap mufrad)

## 2. I'rab

### Tanda I'rab Asli
| Keadaan | Tanda | Contoh |
|---------|-------|--------|
| Marfu' | Dhammah ـُ | الْكِتَابُ |
| Manshub | Fathah ـَ | الْكِتَابَ |
| Majrur | Kasrah ـِ | الْكِتَابِ |
| Majzum | Sukun ـْ | لَمْ يَكْتُبْ |

### Tanda I'rab Pengganti (Niabah)
| Jenis Isim | Marfu' | Manshub | Majrur |
|------------|--------|---------|--------|
| Mutsanna | ـَانِ | ـَيْنِ | ـَيْنِ |
| Jamak mudzakkar salim | ـُوْنَ | ـِيْنَ | ـِيْنَ |
| Jamak mu'annats salim | ـَاتٌ | ـَاتٍ | ـَاتٍ |
| Asma' khamsah | و | ي | ي |
| Isim ghoiru munsharif | dhammah | fathah | **fathah** (bukan kasrah) |
| Fi'il af'al khamsah | ـُوْنَ/تُوْنَ | ـُوا/تُوا | ـُوا/تُوا |

### Isim Mabni (Tidak ber-i'rab)
Isim yang tidak berubah bentuknya:
- Dhamir (kata ganti): هُوَ، هِيَ، أَنْتَ، أَنَا، نَحْنُ...
- Isim isyarah (kata tunjuk): هَذَا، هَذِهِ، ذَلِكَ، تِلْكَ...
- Isim maushul: الَّذِي، الَّتِي، الَّذِيْنَ...
- Isim istifham: مَنْ، مَا، أَيْنَ، كَيْفَ، مَتَى...
- Isim syarat: إِنْ، مَنْ، مَا، أَيْنَمَا...

## 3. Nawasikh Ismiyyah

### 3a. إِنَّ وَأَخَوَاتُهَا (Inna dan Saudara-saudaranya)
Mengubah i'rab: **mubtada → manshub (isim inna), khabar → tetap marfu'**

| Huruf | Makna | Contoh |
|-------|-------|--------|
| إِنَّ | Sesungguhnya (taukid) | إِنَّ اللهَ غَفُوْرٌ |
| أَنَّ | Bahwa (untuk klausa benda) | عَلِمْتُ أَنَّ الْحَقَّ وَاضِحٌ |
| كَأَنَّ | Seolah-olah (tasybih) | كَأَنَّ الْبَدْرَ وَجْهُهُ |
| لَكِنَّ | Akan tetapi (istidrak) | جَاءَ زَيْدٌ لَكِنَّ عَمْرًا غَائِبٌ |
| لَيْتَ | Seandainya (tamanni) | لَيْتَ الشَّبَابَ يَعُوْدُ |
| لَعَلَّ | Semoga/mungkin (taraji) | لَعَلَّ الْمَرِيْضَ يَشْفَى |

> ⚠️ Jika isim inna didahului ma (ما الكافة): إِنَّمَا → tidak beramal lagi

### 3b. كَانَ وَأَخَوَاتُهَا (Kana dan Saudara-saudaranya)
Masuk ke jumlah ismiyyah: **mubtada (isim kana) → tetap marfu', khabar (khabar kana) → manshub**

**Kana Tammah vs Naqishah:**
- **Naqishah**: butuh isim + khabar → كَانَ الْجَوُّ بَارِدًا
- **Tammah**: hanya butuh fa'il → كَانَ اللَّيْلُ (malam telah tiba)

| Fi'il | Makna |
|-------|-------|
| كَانَ | Adalah/telah ada (masa lalu) |
| أَصْبَحَ | Menjadi di pagi hari / menjadi |
| أَمْسَى | Menjadi di sore hari |
| أَضْحَى | Menjadi di waktu dhuha |
| ظَلَّ | Terus menerus (siang) |
| بَاتَ | Terus menerus (malam) |
| صَارَ | Menjadi (berubah) |
| مَا زَالَ | Masih terus |
| مَا فَتِئَ | Tidak henti-hentinya |
| مَا بَرِحَ | Tidak beranjak dari |
| مَا انْفَكَّ | Tidak lepas dari |
| لَيْسَ | Bukan/tidak (nafyi) |

**Kana dalam berbagai zaman:**
- كَانَ يَكْتُبُ = sedang menulis (masa lalu berulang)
- كَانَ قَدْ كَتَبَ = telah menulis (masa lampau sempurna)

### 3c. أَفْعَال الْمُقَارَبَةِ وَالرَّجَاءِ وَالشُّرُوعِ
Beramal seperti kana, khabar wajib berupa fi'il mudhari':

| Fi'il | Makna | Contoh |
|-------|-------|--------|
| كَادَ / يَكَادُ | Hampir saja | كَادَ الْفَجْرُ يَطْلُعُ |
| أَوْشَكَ | Hampir saja | أَوْشَكَ الْمَطَرُ أَنْ يَنْزِلَ |
| عَسَى | Semoga/mungkin | عَسَى اللهُ أَنْ يَرْحَمَنَا |
| حَرَى | Patut/layak | حَرَى الطَّالِبُ أَنْ يَنْجَحَ |
| شَرَعَ | Mulai | شَرَعَ يَكْتُبُ |
| جَعَلَ | Mulai/terus | جَعَلَ يَبْكِي |
| أَخَذَ | Mulai | أَخَذَ يَقْرَأُ |
| طَفِقَ | Mulai | طَفِقَ يَشْتَغِلُ |

## 4. Maf'ulat (Isim-isim yang Selalu Manshub)

### 4a. Maf'ul Bih (Objek Langsung)
Yang dikenai tindakan fi'il transitif.
كَتَبَ الطَّالِبُ **الدَّرْسَ**

### 4b. Maf'ul Mutlaq (Objek Absolut)
Masdar dari fi'il yang sama, berfungsi untuk menguatkan atau menjelaskan cara.
- Taukid: ضَرَبْتُهُ **ضَرْبًا** (aku memukulnya dengan sungguh-sungguh)
- Nau': ضَرَبْتُهُ **ضَرْبَ الْمُؤَدِّبِ** (memukulnya seperti pukulan pendidik)

### 4c. Maf'ul Lahu / Li Ajlih (Objek Tujuan)
Menjelaskan alasan dilakukannya perbuatan.
جِئْتُ **طَلَبًا لِلْعِلْمِ** (aku datang karena mencari ilmu)

Syarat: masdar, nakirah, satu pelaku dengan fi'il, satu waktu.

### 4d. Maf'ul Fih / Zharaf (Keterangan Waktu & Tempat)
Isim zaman atau makan dalam posisi manshub.
- Zaman: صُمْتُ **يَوْمَ الْجُمُعَةِ**
- Makan: جَلَسْتُ **أَمَامَ الْبَيْتِ**

### 4e. Maf'ul Ma'ah (Objek Penyerta)
Setelah wawu ma'iyyah (و yang bermakna "bersama").
سِرْتُ **وَالنَّهْرَ** (aku berjalan bersama/menelusuri sungai)

### 4f. Hal (Keterangan Keadaan)
Menerangkan keadaan fa'il/maf'ul saat perbuatan berlangsung.
- Harus nakirah (atau syibhul jumlah)
- Harus sesuai gender dengan shahibul hal
جَاءَ الرَّجُلُ **رَاكِبًا** (lelaki itu datang dalam keadaan berkuda)
رَأَيْتُهُ **مُسْرِعًا** (aku melihatnya dalam keadaan tergesa-gesa)

**Hal jumlah** (berupa kalimat):
- Jumlah ismiyyah: جَاءَ وَهُوَ فَرِحٌ
- Jumlah fi'liyyah: جَاءَ يَضْحَكُ

### 4g. Tamyiz (Penjelas/Perinci)
Merinci keambiguan sebuah bilangan, ukuran, atau kalimat.
- Tamyiz mufrad: عِنْدِي عِشْرُوْنَ كِتَابًا
- Tamyiz jumlah: طَابَ زَيْدٌ نَفْسًا (Zaid baik jiwanya)
- Setelah ukuran: اشْتَرَيْتُ رِطْلًا زَيْتًا

### 4h. Munada (Seruan/Vokativ)
Setelah huruf nida' (يَا، أَيُّهَا، أَيَّتُهَا، هَيَا، أَيَا):
- Munada 'alam mufrad: يَا **زَيْدُ** → marfu' lafzhon, manshub mahalan
- Munada nakirah maqshudah: يَا **رَجُلُ**
- Munada mudhaf: يَا **عَبْدَ اللهِ** → manshub
- Munada syibhul mudhaf: يَا **كَرِيمًا خُلُقُهُ** → manshub

### 4i. Mustatsna (Pengecualian — lihat juga §7)
جَاءَ الْقَوْمُ **إِلَّا زَيْدًا**

## 5. Tawabi' (Kata Pengikut)

Semua tawabi' mengikuti i'rab kata yang diikutinya (matbu'):

### 5a. Na't (Kata Sifat / Adjektiva)
Mengikuti man'ut dalam: i'rab, gender, jumlah, ma'rifah/nakirah.

| Man'ut | Na't |
|--------|------|
| رَجُلٌ | كَرِيْمٌ |
| الرَّجُلُ الْكَرِيْمُ | (keduanya ma'rifah) |
| رِجَالٌ كِرَامٌ | (na't jamak taksir → mufrad mu'annats) |

> ⚠️ Na't untuk jamak non-manusia diperlakukan sebagai mu'annats mufrad:
> كُتُبٌ مُفِيْدَةٌ (bukan مُفِيْدُوْنَ)

**Na't Sababi**: na't tidak mengikuti man'ut tapi mengikuti dhamirnya:
جَاءَ رَجُلٌ كَرِيْمَةٌ أُمُّهُ (lelaki yang mulia ibunya)

### 5b. 'Athaf (Kata Sambung)
Kata setelah harf 'athaf mengikuti i'rab kata sebelumnya (ma'thuf 'alaih).

| Harf 'Athaf | Makna |
|-------------|-------|
| وَ | Dan (mutlak) |
| فَ | Kemudian (langsung/berurutan) |
| ثُمَّ | Kemudian (ada jeda) |
| أَوْ | Atau |
| أَمْ | Atau (dalam pertanyaan) |
| بَلْ | Bahkan/melainkan |
| لَا | Tidak (nafyi athaf) |
| لَكِنْ | Akan tetapi (istidrak ringan) |
| حَتَّى | Hingga/bahkan |

### 5c. Taukid (Penegasan)
Dua jenis:
- **Lafdzi**: mengulang kata yang sama → جَاءَ زَيْدٌ زَيْدٌ
- **Ma'nawi**: menggunakan kata penegas khusus (harus idhafah ke dhamir):

| Kata Taukid | Makna |
|-------------|-------|
| نَفْسُ / عَيْنُ | Diri sendiri / tepat |
| كُلُّ / جَمِيْعُ | Semua |
| كِلَا / كِلْتَا | Keduanya (mudzakkar/mu'annats) |
| أَجْمَعُ / أَكْتَعُ | Seluruhnya |

Contoh: جَاءَ الطُّلَّابُ كُلُّهُمْ

### 5d. Badal (Pengganti)
Kata yang menggantikan/merinci kata sebelumnya (mubdal minh):

| Jenis | Contoh |
|-------|--------|
| Badal kull min kull | جَاءَ أَخُوْكَ زَيْدٌ |
| Badal ba'd min kull | أَكَلْتُ الرَّغِيْفَ ثُلُثَهُ |
| Badal isytimal | نَفَعَنِي زَيْدٌ عِلْمُهُ |
| Badal ghalath (koreksi) | قَرَأْتُ كِتَابًا قِصَّةً |

## 6. Uslub Syarat (Kalimat Kondisional)

Struktur: **Adat Syarat + Fi'il Syarat + Jawab Syarat**

| Adat Syarat | Makna | Fi'il Syarat | Jawab Syarat |
|-------------|-------|--------------|--------------|
| إِنْ | Jika (umum) | Majzum | Majzum |
| مَنْ | Siapa yang | Majzum | Majzum |
| مَا | Apa yang | Majzum | Majzum |
| مَهْمَا | Apapun yang | Majzum | Majzum |
| إِذْمَا | Kapanpun | Majzum | Majzum |
| أَيْنَمَا | Di manapun | Majzum | Majzum |
| أَيَّانَمَا | Kapanpun | Majzum | Majzum |
| أَيٌّ | Yang mana saja | Majzum | Majzum |
| لَوْ | Jika (mustahil) | Madhi | — (jawab dengan لَـ) |
| لَوْلَا | Seandainya bukan | Mubtada | — (jawab dengan لَـ) |
| لَمَّا | Tatkala | Madhi | Madhi |
| كُلَّمَا | Setiap kali | Madhi | Madhi |

**Contoh:**
- إِنْ تَدْرُسْ تَنْجَحْ (jika kamu belajar, kamu berhasil)
- لَوْ دَرَسْتَ لَنَجَحْتَ (seandainya kamu belajar, niscaya kamu berhasil — tapi tidak)
- لَوْلَا الْعِلْمُ لَهَلَكَ النَّاسُ (seandainya bukan karena ilmu, manusia akan binasa)

**Jawab syarat dengan fa':** Jika jawab berupa jumlah ismiyyah, fi'il madhi, fi'il amar, atau nafyi, wajib didahului فَ:
إِنْ تَجِئْ **فَأَنَا مَسْرُوْرٌ**

## 7. Uslub Istitsna (Pengecualian)

### Istitsna dengan إِلَّا
- **Kalau kalimat positif & sempurna** → mustatsna manshub:
  جَاءَ الطُّلَّابُ إِلَّا **زَيْدًا**
- **Kalau kalimat negatif & sempurna** → boleh manshub atau badal:
  مَا جَاءَ أَحَدٌ إِلَّا **زَيْدًا / زَيْدٌ**
- **Kalau kalimat tidak sempurna (istitsna mufrarragh)** → i'rab sesuai posisinya:
  مَا جَاءَ إِلَّا **زَيْدٌ** (fa'il → marfu')

### Istitsna dengan غَيْرُ dan سِوَى
Berlaku seperti idhafah; i'rab غَيْر/سِوَى sesuai posisi mustatsna:
جَاءَ الطُّلَّابُ **غَيْرَ** زَيْدٍ (manshub karena posisi mustatsna)

### Istitsna dengan خَلَا، عَدَا، حَاشَا
Mustatsna boleh manshub (fi'l) atau majrur (harf jar):
جَاءُوا خَلَا زَيْدًا / خَلَا زَيْدٍ

## 8. Uslub Ta'ajjub (Kekaguman)

### Shighah Pertama: مَا أَفْعَلَهُ
مَا + fi'il madhi wazan أَفْعَلَ + dhamir manshub:
**مَا أَجْمَلَ السَّمَاءَ!** (Betapa indahnya langit!)

- مَا: mubtada marfu' (nakirah tammah)
- أَجْمَلَ: fi'il madhi, fa'ilnya dhamir tersembunyi (هو merujuk ما)
- السَّمَاءَ: maf'ul bih manshub

### Shighah Kedua: أَفْعِلْ بِهِ
Fi'il amar dari wazan أَفْعَلَ + بِ + fa'il majrur lafzhon (marfu' mahalan):
**أَجْمِلْ بِالسَّمَاءِ!** (Alangkah indahnya langit!)

> ⚠️ Ta'ajjub hanya boleh dari fi'il tsulatsi, bukan dari warna/cacat/fi'il jami', kecuali melalui perantara.

---

## 9. Uslub Madh wa Dzamm (Pujian & Celaan)

### نِعْمَ وَبِئْسَ
Struktur: **نِعْمَ/بِئْسَ + fa'il + makhshush (subjek yang dipuji/dicela)**

| Elemen | I'rab |
|--------|-------|
| نِعْمَ/بِئْسَ | Fi'il madhi mabni |
| Fa'il | Marfu' (ma'rifah dengan ال atau mudhaf) |
| Makhshush | Mubtada muakhar (jika nakirah) atau khabar mubtada (jika ma'rifah) |

Contoh:
- نِعْمَ الرَّجُلُ زَيْدٌ (sebaik-baik lelaki adalah Zaid)
- نِعْمَ رَجُلًا زَيْدٌ (Zaid adalah sebaik-baik lelaki)
- بِئْسَ الْخُلُقُ الْكَذِبُ (seburuk-buruk perangai adalah kebohongan)

### حَبَّذَا وَلَا حَبَّذَا
حَبَّذَا: fi'il + fa'il (ذَا) — makhshush adalah mubtada:
حَبَّذَا الصِّدْقُ (alangkah baiknya kejujuran)

## 10. Asma' Khamsah (Lima Isim Khusus)

Lima isim ini ber-i'rab dengan **huruf** (bukan harakat) jika:
- Mudhaf
- Mudhaf ilaih bukan ya' mutakallim
- Mufrad

| Isim | Marfu' | Manshub | Majrur |
|------|--------|---------|--------|
| أَبٌ (ayah) | أَبُوْكَ | أَبَاكَ | أَبِيْكَ |
| أَخٌ (saudara) | أَخُوْكَ | أَخَاكَ | أَخِيْكَ |
| حَمٌ (ipar laki) | حَمُوْكَ | حَمَاكَ | حَمِيْكَ |
| فٌو (mulut) | فُوْكَ | فَاكَ | فِيْكَ |
| ذُو (yang memiliki) | ذُوْ مَالٍ | ذَا مَالٍ | ذِيْ مَالٍ |

> ⚠️ Jika tidak mudhaf atau mudhaf ke ya', kembali ke i'rab biasa dengan harakat.

## 11. Isim Ghoiru Munsharif

Isim yang tidak menerima **tanwin** dan **kasrah**. Majrurnya menggunakan **fathah**.

### Sebab-sebab Ghoiru Munsharif
**Satu sebab (jika 'illah wustha):**
- Tanda mu'annats (ة atau alif mamdud/maqshur): فَاطِمَةُ، حَمْرَاءُ، ذِكْرَى
- Wazan fi'il: أَحْمَدُ (wazan أَفْعَل)

**Dua sebab (harus dua 'illah):**
| 'Illah 1 | 'Illah 2 | Contoh |
|----------|----------|--------|
| Isim 'alam | + mu'annats | فَاطِمَةُ، مَكَّةُ |
| Isim 'alam | + 'ujmah | إِبْرَاهِيْمُ، يُوْسُفُ |
| Isim 'alam | + wazan fi'il | أَحْمَدُ، يَزِيْدُ |
| Isim 'alam | + tarkib mazji | بَعْلَبَكَّ، حَضْرَمَوْتَ |
| Isim 'alam | + ziyadah alif nun | عُثْمَانُ، رَمَضَانُ |
| Isim 'alam | + wazan 'adl | عُمَرُ، زُحَلُ |
| Sifat | + wazan أَفْعَل | أَحْمَرُ، أَكْبَرُ |
| Sifat | + ziyadah alif nun | عَطْشَانُ، سَكْرَانُ |
| Jamak | + wazan مَفَاعِل/مَفَاعِيل | مَسَاجِدُ، مَصَابِيْحُ |

> Jika ghoiru munsharif masuk idhafah atau didahului ال → boleh kasrah kembali:
> مَرَرْتُ بِالْمَسَاجِدِ / بِمَسَاجِدِ الْمَدِيْنَةِ

## 12. Zharaf (Keterangan Waktu & Tempat)

### Zharaf Zaman (Waktu)

## 14. Fi'il Majhul (Pasif)

### Pembentukan Majhul
**Fi'il madhi:**
- Tsulatsi: dhammah huruf pertama + kasrah huruf sebelum terakhir → كُتِبَ
- Ruba'i: dhammah dua huruf pertama + kasrah huruf sebelum terakhir → دُحْرِجَ
- Mazid: dhammah huruf pertama + kasrah huruf sebelum terakhir: أُكْرِمَ، اُنْكُسِرَ، اُسْتُخْرِجَ

**Fi'il mudhari':**
- Dhammah huruf mudharaah + fathah huruf sebelum terakhir → يُكْتَبُ، يُدَحْرَجُ

### Naibul Fa'il
Menjadi subjek kalimat pasif, i'rabnya marfu':
قُرِئَ **الْكِتَابُ** (buku itu dibaca)
Jika tidak ada maf'ul bih → jar-majrur atau zharaf bisa jadi naibul fa'il:
سِيْرَ **فِي الطَّرِيْقِ** (jalan itu telah ditempuh)

## 15. Kalimat Majemuk & Konjungsi

### Majemuk Setara (dengan harf 'athaf — lihat §5b)

### Majemuk Bertingkat (Klausa)
- **Klausa benda (jumlah fi mahall raf'/nashb/jar)**:
  عَلِمْتُ أَنَّ الْحَقَّ مَنْصُوْرٌ
- **Klausa sifat (jumlah fi mahall jarr/nashb — na't)**:
  جَاءَ رَجُلٌ يَحْمِلُ كِتَابًا
- **Klausa keterangan (jumlah fi mahall nashb — hal)**:
  دَخَلَ وَهُوَ يَبْتَسِمُ

### Konjungsi Penting
| Konjungsi | Makna | Pengaruh Gramatikal |
|-----------|-------|---------------------|
| وَ | Dan | 'Athaf |
| فَ | Maka/lalu | 'Athaf / jawab syarat |
| ثُمَّ | Kemudian | 'Athaf |
| لَكِنَّ | Akan tetapi | Nawasikh / istidrak |
| لِأَنَّ | Karena | — |
| حَتَّى | Sampai/hingga | Nashb fi'il mudhari' |
| كَيْ / لِكَيْ | Agar/supaya | Nashb fi'il mudhari' |

| إِذَنْ | Kalau begitu | Nashb fi'il mudhari' (dengan syarat) |

### Nawashib Fi'il Mudhari'
Fi'il mudhari' manshub setelah: أَنْ، لَنْ، كَيْ، لِـ (ta'lil)، حَتَّى، فَ (jawab)، وَ (ma'iyyah)

### Jawazim Fi'il Mudhari'
Fi'il mudhari' majzum setelah: لَمْ، لَمَّا، لَا (nahi)، لَامُ الْأَمْر، adat syarat

## 16. 'Adad (Bilangan)

Sistem bilangan Arab sangat kompleks karena **mukhالفah (perbedaan gender)**.

### Bilangan 1-2
- Mengikuti gender ma'dud: كِتَابٌ وَاحِدٌ، وَرَقَةٌ وَاحِدَةٌ
- Mutsanna: كِتَابَانِ، وَرَقَتَانِ

### Bilangan 3-10 (Mukhâlafah)
'Adad berlawanan gender dengan ma'dud:
- ثَلَاثَةُ كُتُبٍ (buku: mudzakkar → 'adad mu'annats)
- ثَلَاثُ وَرَقَاتٍ (kertas: mu'annats → 'adad mudzakkar)
- Ma'dud: jamak majrur (mudhaf ilaih)

### Bilangan 11-12 (Mabni)
Kedua bagian mengikuti gender ma'dud:
- أَحَدَ عَشَرَ كِتَابًا / إِحْدَى عَشْرَةَ وَرَقَةً
- اثْنَا عَشَرَ كِتَابًا / اثْنَتَا عَشْرَةَ وَرَقَةً
- Ma'dud: mufrad manshub (tamyiz)

### Bilangan 13-19 (Mukhâlafah pada bagian pertama)
الجزء الأول: mukhâlafah; الجزء الثاني: sesuai ma'dud:
- ثَلَاثَةَ عَشَرَ كِتَابًا (masc) / ثَلَاثَ عَشْرَةَ وَرَقَةً (fem)

### Bilangan 20-99 (Mulhaq bilfard)
'Adad tidak berubah gender:
- عِشْرُوْنَ كِتَابًا / عِشْرُوْنَ وَرَقَةً
- Ma'dud: mufrad manshub (tamyiz)

### Bilangan 100, 1000
مِئَةُ كِتَابٍ / أَلْفُ كِتَابٍ — ma'dud mufrad majrur

### Bilangan Urutan (عدد ترتيبي)
Wazan فَاعِل: الْأَوَّلُ، الثَّانِي، الثَّالِثُ... mengikuti gender ma'dud

## 19. Mahall I'rab Jumlah (I'rab Kalimat/Klausa)

> ⚠️ Bab ini wajib dibaca saat menganalisis klausa bersarang atau kalimat majemuk.

I'rab tidak hanya berlaku pada kata, tetapi juga pada **jumlah (kalimat/klausa)** yang menduduki posisi gramatikal tertentu.

### 19a. Jumlah yang Memiliki Mahall I'rab

| Posisi Jumlah | Mahall | Contoh |
|---------------|--------|--------|
| Khabar mubtada | في محل رفع | الطَّالِبُ **يَدْرُسُ** (يدرس = khabar, fi mahall raf') |
| Khabar kana | في محل نصب | كَانَ الْجَوُّ **يَمْطُرُ** (يمطر = khabar kana, fi mahall nashb) |
| Khabar inna | في محل رفع | إِنَّ الْعِلْمَ **نَافِعٌ** — jika khabar berupa jumlah |
| Maf'ul bih | في محل نصب | عَلِمْتُ **أَنَّ الْحَقَّ مَنْصُوْرٌ** (jumlah = maf'ul bih fi'il 'ilmiyyah) |
| Hal | في محل نصب | جَاءَ الرَّجُلُ **وَهُوَ يَبْتَسِمُ** (jumlah = hal) |
| Na't (sifat) | في محل جر/رفع/نصب | جَاءَ رَجُلٌ **يَحْمِلُ كِتَابًا** (jumlah = na't untuk رجل) |
| Jawab syarat (jazm) | في محل جزم | إِنْ تَدْرُسْ **تَنْجَحْ** (تنجح = jawab syarat, fi mahall jazm) |
| Mudhaf ilaih | في محل جر | — (jarang, hanya dengan يَوْمَ dan sejenisnya) |

**Cara analisis:**
1. Tentukan fungsi klausa dalam kalimat induk (sebagai apa?)
2. Sebutkan: *"jumlah [X] fi mahall [Y] karena [alasan]"*
3. Contoh lengkap: جَاءَ رَجُلٌ يَحْمِلُ كِتَابًا
   - يَحْمِلُ كِتَابًا → **jumlah fi'liyyah fi mahall jarr na'tan li-rajulin**

---

### 19b. Jumlah yang TIDAK Memiliki Mahall I'rab (لا محل لها)

Jumlah-jumlah berikut **tidak menduduki posisi gramatikal** apapun dalam kalimat induk:

| Jenis Jumlah | Keterangan | Contoh |
|--------------|------------|--------|
| **Jumlah ibtida'iyyah** | Kalimat pembuka/mandiri | اَلْعِلْمُ نُوْرٌ (kalimat utama) |
| **Shilah al-maushul** | Klausa penjelas isim maushul | الرَّجُلُ الَّذِي **جَاءَ أَبُوْهُ** كَرِيْمٌ → جاء أبوه = shilah, lا محل لها |
| **Jumlah mu'taridhah** | Klausa sisipan/parenthetical | قَالَ — **وَهُوَ الصَّادِقُ** — إِنَّ الْحَقَّ مَنْصُوْرٌ |
| **Jawab qasam** | Jawaban sumpah | وَاللهِ **لَأَفْعَلَنَّ** |
| **Jawab syarat ghairu jazim** | Jawaban لَوْ، لَوْلَا، لَمَّا | لَوْ دَرَسْتَ **لَنَجَحْتَ** → لنجحت = لا محل لها |
| **Jumlah tafsiriyyah** | Klausa penjelas | أَشَارَ إِلَيْهِ **أَيْ نَادَاهُ** |

> ⚠️ **Kesalahan umum:** Shilah al-maushul sering keliru diberi mahall i'rab. Ingat: shilah al-maushul **selalu لا محل لها**, bukan fi mahall jarr.

## 20. Af'al Qalbiyyah (Verba Mental/Persepsi)

> ⚠️ Bab ini wajib dibaca saat teks mengandung verba persepsi/mental yang diikuti dua objek.

Af'al qalbiyyah adalah fi'il yang menunjukkan **aktivitas mental atau persepsi** dan membutuhkan **dua maf'ul bih** (objek ganda).

### 20a. Daftar Af'al Qalbiyyah

| Fi'il | Makna | Catatan |
|-------|-------|---------|
| ظَنَّ | Menyangka / mengira | Paling umum |
| حَسِبَ | Menghitung / mengira | Setara ظن |
| خَالَ | Membayangkan | |
| زَعَمَ | Mengklaim | Sering konotatif negatif |
| رَأَى | Melihat / berpendapat | Jika bermakna ra'yul 'aql (pendapat) → qalbiyyah |
| وَجَدَ | Mendapati / menemukan | |
| عَلِمَ | Mengetahui | |
| وَجَدَ | Mendapati | |
| جَعَلَ | Menjadikan | Bermakna transformasi |
| اتَّخَذَ | Menjadikan / mengambil | |

### 20b. Struktur dan I'rab

```
ظَنَنْتُ زَيْدًا قَائِمًا
```

| Kata | I'rab |
|------|-------|
| ظَنَنْتُ | Fi'il madhi + fa'il (تُ) |
| زَيْدًا | **مفعول به أول** — manshub |
| قَائِمًا | **مفعول به ثانٍ** — manshub |

**Analogi dengan mubtada-khabar:**
- Maf'ul awwal = mubtada asal (sebelum dimasuki ظن)
- Maf'ul tsani = khabar asal

### 20c. Contoh dalam Teks Akademik

```
يَرَى الْبَاحِثُ الْمَنْهَجَ الْوَصْفِيَّ مُنَاسِبًا لِهَذِهِ الدِّرَاسَةِ
```
- الْبَاحِثُ → fa'il
- الْمَنْهَجَ الْوَصْفِيَّ → **maf'ul bih awwal** (manshub)
- مُنَاسِبًا → **maf'ul bih tsani** (manshub)
- Terjemahan: *"Peneliti memandang metode deskriptif sebagai [metode yang] sesuai untuk penelitian ini"*

### 20d. Af'al Qalbiyyah yang Membutuhkan أَنَّ

Jika diikuti أَنَّ, maka jumlah sesudahnya = maf'ul bih tunggal (satu objek berupa klausa):
```
عَلِمَ الطُّلَّابُ أَنَّ الِامْتِحَانَ غَدًا
```
- أَنَّ الِامْتِحَانَ غَدًا → **في محل نصب مفعول به**

## 21. Taqdim wa Ta'khir (Pendepanan & Pengebelakangan)

> ⚠️ Bab ini wajib dibaca saat urutan kata dalam kalimat Arab tidak mengikuti pola dasar.

Arab memiliki fleksibilitas urutan kata yang tinggi. Pendepanan/pengebelakangan terjadi untuk tujuan **retoris, penekanan, atau ketentuan gramatikal**.

### 21a. Jenis-jenis Taqdim

**① Taqdim Wajib (maf'ul bih atau khabar harus didepankan):**

| Kasus | Contoh | Alasan |
|-------|--------|--------|
| Khabar berupa isim istifham | كَيْفَ أَنْتَ؟ | Isim istifham selalu di awal |
| Maf'ul bih berupa isim istifham | مَاذَا تَدْرُسُ؟ | Isim istifham selalu di awal |
| Mubtada yang jika diakhirkan akan ambigu | أُسْتَاذِي أَنَا | Tanpa taqdim, makna berubah |

**② Taqdim Jaiz (boleh, untuk penekanan/uslub):**

| Yang didepankan | Makna Retoris | Contoh |
|-----------------|---------------|--------|
| Maf'ul bih | Penekanan objek | الدَّرْسَ كَتَبَ الطَّالِبُ |
| Khabar | Penekanan predikat | نَاجِحٌ هُوَ |
| Zharaf / jar-majrur | Penekanan waktu/tempat | فِي الْمَكْتَبَةِ يَدْرُسُ |

### 21b. Cara Analisis

Langkah wajib saat menemukan urutan kata tidak lazim:
1. **Identifikasi** elemen mana yang berpindah posisi
2. **Tentukan i'rab** berdasarkan fungsi aslinya (bukan posisinya)
3. **Catat** sebagai taqdim dalam analisis

**Contoh analisis lengkap:**
```
الدَّرْسَ كَتَبَ الطَّالِبُ
```
- الدَّرْسَ → **مفعول به مقدَّم** — manshub (bukan fa'il!)
- كَتَبَ → fi'il
- الطَّالِبُ → **fa'il** — marfu'
- Terjemahan: *"Pelajaran itu [lah yang] ditulis oleh sang murid"* (penekanan pada objek)

### 21c. Taqdim Khabar atas Mubtada

Wajib didepankan jika:
- Khabar berupa syibhul jumlah dan mubtada nakirah: فِي الدَّارِ رَجُلٌ
- Untuk menghindari ambigu antara khabar dan mubtada

### 21d. Taqdim dalam Teks Akademik

Pola umum dalam karya ilmiah Arab:
```
تَهْدُفُ هَذِهِ الدِّرَاسَةُ إِلَى...   → jumlah fi'liyyah (fi'il didepankan)
مِنْ أَبْرَزِ النَّتَائِجِ أَنَّ...      → khabar (jar-majrur) didepankan
```

## 22. Al-Hadzf (Pembuangan/Elipsis)

> ⚠️ Bab ini wajib dibaca saat ada unsur kalimat yang "hilang" tapi bisa diperkirakan dari konteks.

Al-hadzf adalah penghilangan kata/unsur kalimat yang **sudah diketahui dari konteks** atau **karena ketentuan gramatikal**.

### 22a. Hadzf Fa'il (Elipsis Subjek)

Fa'il tersembunyi pada fi'il mudhari' dan amar:

| Bentuk | Fa'il Tersembunyi | Contoh |
|--------|-------------------|--------|
| أَكْتُبُ | أَنَا (mutakallim) | أَكْتُبُ الرِّسَالَةَ |
| تَكْتُبُ | أَنْتَ (mukhathab) | تَكْتُبُ كُلَّ يَوْمٍ |
| اُكْتُبْ | أَنْتَ (amar) | اُكْتُبِ الدَّرْسَ |
| يَكْتُبُ | هُوَ (ghaib) | يَكْتُبُ الطَّالِبُ |

**Hadzf dalam sumpah:**
```
وَاللهِ لَأَفْعَلَنَّ
```
- Fa'il أَنَا tersembunyi dalam لَأَفْعَلَنَّ
- Mubtada محذوف dalam جواب القسم

### 22b. Hadzf Mubtada atau Khabar

**Hadzf mubtada** (umum dalam percakapan/respons):
```
مَنْ جَاءَ؟ — زَيْدٌ.
```
- Aslinya: هُوَ زَيْدٌ (mubtada محذوف)

**Hadzf khabar** (umum setelah qasam atau konteks jelas):
```
لَعَمْرُكَ [قَسَمِي] ...
```

### 22c. Hadzf dalam Jawab Syarat

Jawab syarat sering dibuang jika sudah jelas dari konteks:
```
مَنْ صَبَرَ [نَالَ مُرَادَهُ]
```
Kata yang dibuang bisa dipulihkan dari konteks sebelumnya.

### 22d. Hadzf Maf'ul Bih

Sering terjadi pada fi'il yang objeknya sudah diketahui:
```
مَنْ أَرَادَ [ذَلِكَ] فَلْيَفْعَلْ
```

### 22e. Panduan Analisis

Saat menemukan kalimat yang "tidak lengkap":
1. Identifikasi unsur mana yang hilang (fa'il? mubtada? khabar? maf'ul?)
2. Pulihkan unsur tersebut dalam tanda kurung siku `[...]`
3. Catat sebagai: *"[X] محذوف — diperkirakan: [Y]"*

## 23. Al-Qashr (Pembatasan/Eksklusi)

> ⚠️ Bab ini wajib dibaca saat teks mengandung إِنَّمَا, نَفْي + إِلَّا, atau taqdim yang bersifat pembatasan. Bab ini berkaitan dengan §3 (Nawasikh) dan §7 (Istitsna).

Al-qashr adalah **membatasi satu sifat/hukum hanya pada satu hal**, mengeksklusi yang lain.

### 23a. Jenis Qashr

**① Qashr Haqiqi** — pembatasan mutlak (hanya berlaku pada satu hal secara nyata)
**② Qashr Idhafi** — pembatasan relatif (dibandingkan dengan anggapan lawan bicara)

### 23b. Cara Membentuk Qashr

| Metode | Struktur | Contoh | Terjemahan |
|--------|----------|--------|------------|
| **إِنَّمَا** | إِنَّمَا + jumlah | إِنَّمَا الْعِلْمُ نُوْرٌ | Ilmu itu tidak lain hanyalah cahaya |
| **نَفْي + إِلَّا** | مَا/لَا + ... + إِلَّا | مَا مُحَمَّدٌ إِلَّا رَسُوْلٌ | Muhammad tidak lain hanyalah seorang rasul |
| **تَقْدِيْم مَا حَقُّهُ التَّأْخِيْر** | Mendepankan unsur | إِيَّاكَ نَعْبُدُ | Hanya kepada-Mu kami menyembah |
| **عَطْف بِـ لَا أَوْ بَلْ أَوْ لَكِنْ** | X بَلْ/لَا Y | جَاءَ زَيْدٌ لَا عَمْرٌو | Yang datang Zaid, bukan Amr |

### 23c. Analisis إِنَّمَا

```
إِنَّمَا الْعِلْمُ نُوْرٌ
```
- إِنَّمَا = إِنَّ + مَا الكافة → **inna kehilangan amalnya** (tidak menashabkan)
- الْعِلْمُ → **mubtada marfu'** (bukan isim inna!)
- نُوْرٌ → **khabar marfu'**
- Makna qashr: *"Yang merupakan cahaya itu tidak lain hanyalah ilmu"*

> ⚠️ **Kesalahan kritis:** إِنَّمَا ≠ إِنَّ. Jika ada مَا الكافة setelah إِنَّ, amal nawasikh gugur — mubtada tetap marfu', bukan manshub.

### 23d. Analisis Nafi + Istitsna

```
مَا النَّجَاحُ إِلَّا ثَمَرَةُ الْجِدِّ
```
- مَا → nafiyah (نافية)
- النَّجَاحُ → mubtada marfu'
- إِلَّا → adat istitsna (di sini: li al-qashr)
- ثَمَرَةُ الْجِدِّ → **khabar** (bukan mustatsna manshub, karena kalimat negatif tidak sempurna → badal / khabar)
- Makna: *"Keberhasilan tidak lain hanyalah buah dari ketekunan"*

### 23e. Qashr dalam Teks Akademik

Pola yang sering muncul:
```
إِنَّمَا يَهْدُفُ هَذَا الْبَحْثُ إِلَى...     → pembatasan tujuan
لَا يَتَحَقَّقُ ذَلِكَ إِلَّا بِـ...           → pembatasan syarat
مَا الْمَنْهَجُ الْمُنَاسِبُ إِلَّا...         → pembatasan metodologi
```

## 19. Mahall I'rab Jumlah (I'rab Kalimat)

Kalimat (jumlah) bisa menduduki posisi gramatikal tertentu sehingga memiliki **mahall i'rab** (kedudukan i'rab), meskipun bentuknya tidak berubah.

### Jumlah yang Ber-I'rab (Lahaa Mahallun)

| Posisi | Mahall | Contoh | Keterangan |
|--------|--------|--------|------------|
| Khabar mubtada | في محل رفع | اَلطَّالِبُ **يَدْرُسُ** | Jumlah fi'liyyah sebagai khabar |
| Khabar kana | في محل نصب | كَانَ الْجَوُّ **يَمْطُرُ** | Khabar kana manshub mahalan |
| Khabar inna | في محل رفع | إِنَّ الْعِلْمَ **يَنْفَعُ** | Khabar inna marfu' mahalan |
| Maf'ul bih | في محل نصب | عَلِمْتُ **أَنَّهُ مُجْتَهِدٌ** | Klausa benda sebagai objek |
| Hal | في محل نصب | جَاءَ **وَهُوَ يَبْتَسِمُ** | Jumlah ismiyyah sebagai hal |
| Na't (sifat) | في محل جر / نصب / رفع | جَاءَ رَجُلٌ **يَحْمِلُ كِتَابًا** | Na't untuk nakirah |
| Mudhaf ilaih | في محل جر | يَوْمَ **يَقُوْمُ النَّاسُ** | Setelah zharaf zaman |
| Jawab syarat (jazim) | في محل جزم | إِنْ تَجْتَهِدْ **تَنْجَحْ** | Jawab syarat dengan huruf jazim |

### Cara Menganalisis Jumlah Ber-I'rab

1. Identifikasi **fungsi kalimat** tersebut dalam struktur yang lebih besar
2. Tentukan **posisinya**: apakah menggantikan kata benda / sifat / keterangan?
3. Tentukan **mahall i'rab**-nya sesuai tabel di atas
4. Tulis: *"جملة [X] في محل [Y] [fungsi]"*

**Contoh analisis lengkap:**

> اَلْبَاحِثُ يَرَى أَنَّ النَّتَائِجَ صَحِيْحَةٌ

- اَلْبَاحِثُ = mubtada, marfu'
- يَرَى = fi'il mudhari', fa'ilnya dhamir هو
- أَنَّ النَّتَائِجَ صَحِيْحَةٌ = jumlah ismiyyah (klausa أنّ) → **في محل نصب مفعول به**

## 20. Jumlah yang Tidak Ber-I'rab (Laa Mahalla Laha)

Beberapa jenis kalimat **tidak memiliki mahall i'rab** karena tidak menggantikan posisi kata apapun.

### Daftar Jumlah Laa Mahalla Laha

| No | Jenis | Penjelasan | Contoh |
|----|-------|-----------|--------|
| 1 | **جملة ابتدائية** | Kalimat pembuka / mandiri | اَلْعِلْمُ نُوْرٌ |
| 2 | **صلة الموصول** | Klausa penjelas isim maushul | جَاءَ الَّذِي **يَدْرُسُ** — يدرس: لا محل لها |
| 3 | **جملة جواب القسم** | Jawab sumpah | وَاللهِ **لَأَجْتَهِدَنَّ** |
| 4 | **جملة جواب الشرط غير الجازم** | Jawab syarat dengan أداة غير جازمة (لو، لولا) | لَوِ اجْتَهَدَ **لَنَجَحَ** |
| 5 | **جملة اعتراضية** | Kalimat sisipan di tengah kalimat lain | جَاءَ — وَكَانَ مُسْرِعًا — أَخُوْكَ |
| 6 | **جملة تفسيرية** | Kalimat penjelas yang diawali أي / أن | اُكْتُبْ أَيِ اِبْدَأِ الْآنَ |
| 7 | **جملة تابعة لما لا محل له** | Mengikuti kalimat lain yang juga laa mahalla laha | — |

### Aturan Kritis: Shilah Maushul

> **صلة الموصول دائمًا لا محل لها من الإعراب**

Klausa setelah الذي / التي / الذين / ما / من **tidak pernah memiliki mahall i'rab**.

Bandingkan:
- جَاءَ رَجُلٌ **يَحْمِلُ كِتَابًا** → jumlah na't، **في محل جر** (رجل nakirah)
- جَاءَ الرَّجُلُ **الَّذِي يَحْمِلُ كِتَابًا** → يحمل adalah shilah، **لا محل لها**

## 21. Af'al Qalbiyyah (Verba Mental)

Verba yang menunjukkan aktivitas pikiran/persepsi. Sangat sering muncul dalam **teks akademik**.

### Daftar Af'al Qalbiyyah

| Fi'il | Makna | Keterangan |
|-------|-------|-----------|
| ظَنَّ | Mengira / menduga | Paling umum |
| حَسِبَ | Mengira / menganggap | — |
| خَالَ | Menyangka | Lebih puitis |
| زَعَمَ | Mengklaim / mendakwa | Konotasi negatif |
| رَأَى | Berpendapat / memandang | Sering dalam akademik |
| عَلِمَ | Mengetahui | — |
| وَجَدَ | Mendapati / menemukan | Sering: وَجَدَ الْبَاحِثُ |
| دَرَى | Mengetahui | — |
| هَبْ | Anggaplah | Mabni, hanya untuk amr |

### Struktur: Dua Maf'ul Bih

Af'al qalbiyyah mengambil **dua maf'ul bih** (bukan satu):

```
Fi'il + Maf'ul bih 1 (= mubtada asli) + Maf'ul bih 2 (= khabar asli)
```

| Elemen | I'rab | Contoh |
|--------|-------|--------|
| Maf'ul bih pertama | Manshub | ظَنَنْتُ **زَيْدًا** قَائِمًا |
| Maf'ul bih kedua | Manshub | ظَنَنْتُ زَيْدًا **قَائِمًا** |

**Contoh dalam konteks akademik:**

> يَرَى الْبَاحِثُ هَذِهِ النَّتِيْجَةَ صَحِيْحَةً

- يَرَى = fi'il qalbi
- الْبَاحِثُ = fa'il, marfu'
- هَذِهِ النَّتِيْجَةَ = **مفعول به أول**، manshub
- صَحِيْحَةً = **مفعول به ثان**، manshub

> وَجَدَ الدَّارِسُوْنَ الْمَنْهَجَ فَعَّالًا

- الْمَنْهَجَ = maf'ul bih pertama, manshub
- فَعَّالًا = maf'ul bih kedua, manshub

### Ilgha' dan Ta'liq (Pembatalan Amal)

| Kondisi | Nama | Contoh |
|---------|------|--------|
| Fi'il diletakkan di tengah / akhir kalimat | **الإلغاء** | زَيْدٌ ظَنَنْتُ قَائِمٌ |
| Diikuti لام ابتداء, ما النافية, إن, استفهام | **التعليق** | عَلِمْتُ لَزَيْدٌ قَائِمٌ |

> Dalam teks akademik, ilgha' dan ta'liq jarang muncul. Prioritaskan pola dua maf'ul bih.

## 22. Taqdim wa Ta'khir (Pemindahan Posisi Kata)

Arab memiliki fleksibilitas urutan kata. Pemindahan posisi (taqdim) terjadi karena alasan retoris, penekanan, atau keharusan gramatikal.

### Jenis-jenis Taqdim

#### A. Taqdim Wajib

| Kondisi | Contoh | Keterangan |
|---------|--------|-----------|
| Khabar berupa isim istifham | أَيْنَ الْكِتَابُ؟ | Wajib di awal |
| Khabar berupa isim syarat | مَنْ يَجْتَهِدْ يَنْجَحْ | — |
| Mubtada ma'rifah, khabar nakirah syibhul jumlah | فِي الدَّارِ رَجُلٌ | Khabar didahulukan |

#### B. Taqdim Maf'ul Bih (paling sering dalam teks ilmiah)

Untuk penekanan (takhshish / qasr):

```
الدِّرَاسَةَ أَجْرَى الْبَاحِثُ
```

> Maf'ul bih yang dipindah ke depan tetap **manshub** — i'rabnya tidak berubah.

#### C. Taqdim Fa'il (inversi kalimat verbal)

```
الطُّلَّابُ كَتَبُوا الدَّرْسَ
```

- الطلاب = fa'il (bukan mubtada), fi'il menjadi jamak karena fa'il mendahului

Bandingkan urutan normal:
```
كَتَبَ الطُّلَّابُ الدَّرْسَ  ← fi'il mufrad karena fa'il datang setelah fi'il
```

#### D. Taqdim Khabar atas Mubtada

Dibolehkan jika:
- Khabar berupa syibhul jumlah: فِي الدَّارِ رَجُلٌ
- Mubtada nakirah tanpa sifat
- Untuk penekanan retoris

### Langkah Analisis Taqdim wa Ta'khir

1. Ada kata manshub di awal tanpa fi'il sebelumnya? → kemungkinan **مفعول به مقدم**
2. Ada isim marfu' setelah fi'il yang sudah punya fa'il? → kemungkinan **fa'il muqaddam** (inversi)
3. Khabar (syibhul jumlah) mendahului mubtada? → **taqdim khabar**
4. Kembalikan ke urutan asal untuk memastikan analisis benar

**Contoh analisis lengkap:**

> النَّتَائِجَ نَاقَشَ الْبَاحِثُ فِي الْفَصْلِ الْخَامِسِ

- النَّتَائِجَ = **مفعول به مقدم**، manshub (penekanan)
- نَاقَشَ = fi'il madhi
- الْبَاحِثُ = fa'il, marfu'
- فِي الْفَصْلِ الْخَامِسِ = jar-majrur, keterangan

## 23. Error Correction: Fi'il Majhul & Naib Fa'il

Checklist wajib setiap kali ditemukan fi'il majhul dalam teks.

### Checklist Fi'il Majhul

```
LANGKAH 1 — Konfirmasi bentuk majhul:
  [ ] Madhi: huruf pertama dhammah + huruf sebelum akhir kasrah? → كُتِبَ
  [ ] Mudhari': huruf mudharaah dhammah + huruf sebelum akhir fathah? → يُكْتَبُ
  [ ] Jika tidak memenuhi → bukan majhul, periksa ulang

LANGKAH 2 — Cari naib fa'il:
  [ ] Naib fa'il WAJIB ada
  [ ] I'rabnya HARUS marfu'
  [ ] Prioritas: maf'ul bih (1) → jar-majrur (2) → zharaf (3)

LANGKAH 3 — Verifikasi i'rab naib fa'il:
  [ ] Sudah marfu'? → lanjut
  [ ] Jika tidak → KOREKSI, catat di catatan kritis

LANGKAH 4 — Muthâbaqah fi'il dan naib fa'il:
  [ ] Naib fa'il mu'annats? → fi'il harus mu'annats: كُتِبَتْ / تُكْتَبُ
  [ ] Naib fa'il mutsanna / jamak setelah fi'il → fi'il tetap mufrad
```

### Contoh Penerapan

**Benar:**
> أُجْرِيَتِ الدِّرَاسَةُ فِي جَامِعَةِ...

- أُجْرِيَتْ = fi'il majhul, mu'annats ✓
- الدِّرَاسَةُ = naib fa'il, marfu' ✓

**Kesalahan umum:**
> اسْتُخْدِمَ الْمَنَاهِجَ ✗

- الْمَنَاهِجَ = manshub → SALAH
- **Koreksi**: اسْتُخْدِمَتِ الْمَنَاهِجُ ✓ (marfu' + fi'il mu'annats karena jamak non-manusia)

### Tabel Kesalahan Umum Fi'il Majhul

| Kesalahan | Penyebab | Koreksi |
|-----------|---------|---------|
| Naib fa'il manshub | Terbawa pola maf'ul bih aktif | Ubah ke marfu' |
| Fi'il tidak muthâbaqah | Lupa jamak non-manusia = mu'annats | Tambah taa' ta'nits |
| Tidak ada naib fa'il | Fi'il dianggap lazim | Cari maf'ul bih atau jadikan jar-majrur sebagai naib fa'il |
| Salah bentuk majhul | Harakat tidak tepat | Periksa ulang pola dhammah-kasrah/fathah |
